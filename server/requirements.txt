# ---------------------------------------------------------------------------
#  server/ — unified Python app (api-py + rag-service merged into one process)
#
#  Combines the dependencies of the former server/api-py/requirements.txt
#  (FastAPI web layer: auth, users, chat/documents routers, SQLAlchemy/
#  Postgres) and server/rag-service/requirements.txt (RAG pipeline: hybrid
#  retrieval, rerank, LLM readers, ChromaDB) into one venv, so the whole app
#  runs as a single `python main.py` process instead of two services talking
#  over HTTP.
#
#  Install torch CPU-only FIRST to avoid pulling the ~2.5 GB CUDA wheel:
#      pip install torch --index-url https://download.pytorch.org/whl/cpu
#      pip install -r requirements.txt
# ---------------------------------------------------------------------------
