# client

Giao diện web (React + Vite + React Router). Xem tài liệu tổng quan ở [README.md](../README.md) tại gốc repo.

```bash
npm run dev            # dev server, cổng 3000
npm run build           # build production vào dist/
npm run preview         # phục vụ thử bản build
npm run lint
```

Định tuyến ở `src/App.tsx`, trang trong `src/pages/`, khung giao diện dùng chung trong `src/layout/`, gọi API qua `src/services/`.
