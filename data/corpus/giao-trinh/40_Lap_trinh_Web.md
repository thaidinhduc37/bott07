## 3. Mô tả học phần

Học phần Lập trình Web là học phần bắt buộc thuộc khối kiến thức cơ sở ngành trong chương trình đào tạo chuyên ngành An toàn hệ thống thông tin, hệ dân sự, trình độ đại học, hình thức chính quy dành cho học viên của Học viện Kỹ thuật và Công nghệ an ninh.

Nội dung học phần: Lập trình Web và triển khai Web Server, một số vấn đề về thiết kế và triển khai Web; thiết kế giao diện Web tĩnh với HTML và CSS; thiết kế Web động với Javascript và PHP; ứng dụng một số Framework mã nguồn mở trong xây dựng ứng dụng Web; kết nối, truy vấn và thao tác với cơ sở dữ liệu MySQL; bảo mật ứng dụng Web.

## 4. Mục tiêu học phần

### 4.1. Về kiến thức

- Trình bày kiến thức cơ bản về Hypertext Markup Language (HTML), Cascading Style Sheets (CSS), Javascript, Front-End Frameworks và Hệ thống quản trị nội dung (Content Management System - CMS); Trình bày kiến thức cơ bản về quản lý máy chủ Web, cơ sở dữ liệu, lập trình Font-End, Back-End và các kiến thức liên quan đến bảo mật ứng dụng Web; các kỹ thuật tối ưu hoá và nâng cao hiệu suất ứng dụng Web;
- Liệt kê một số trình phục vụ Web, ngôn ngữ hỗ trợ lập trình Web, quy trình thiết kế trang Web, các Front-End Framework và các CMS phổ biến;
- So sánh ưu nhược điểm giữa trang Web tĩnh và trang Web động, giữa trang Web sử dụng HTML, CSS và AJAX; Phân biệt giữa Front-End và Back-End; giữa Framework và CMS; Phân biệt các kiểu dữ liệu, các cấu trúc lập trình của ngôn ngữ kịch bản JavaScript và ngôn ngữ lập trình PHP.
- Phân tích cấu trúc của trang Web và cách JavaScript truy xuất đến các thành phần trang Web; Phân tích bài toán theo tư duy lập trình hướng đối tượng.

### 4.2. Về kỹ năng

- Sử dụng thành thạo các thẻ HTML, kết hợp với CSS và AJAX vào thiết kế trang Web; Viết chính xác hàm và sử dụng đúng các đối tượng có sẵn của JavaScript vào thay đổi nội dung và định dạng cho trang Web; Sử dụng ngôn ngữ PHP và CSDL MySQL để xây dựng trang Web có kết nối đến CSDL;
- Xây dựng trang Web động sử dụng kết hợp kiến thức về HTML, CSS, JavaScript, AJAX và PHP;
- Thiết kế Web sử dụng framework hoặc CMS để tăng tốc quá trình phát triển ứng dụng Web;
- Tạo API và xử lý yêu cầu từ Front-End;
- Phát triển kỹ năng làm việc độc lập, kỹ năng làm việc nhóm và kỹ năng thuyết trình.

### 4.3. Năng lực tự chủ và trách nhiệm

- Nhận thức được vai trò và ý nghĩa của môn học gắn liền với thực tiễn.
- Có ý thức tự học hỏi nâng cao hiểu biết về ngôn ngữ.

## 5. Chuẩn đầu ra của học phần

- Có kiến thức chung về lập trình WEB, các kỹ thuật lập trình WEB, vận dụng các kiến thức được học về lập trình WEB để giải quyết các vấn đề liên quan đến lập trình WEB trong học tập, nghiên cứu.
- Có kỹ năng phân tích, thiết kế và xây dựng trang WEB. Vận dụng các kỹ năng lập trình HTML, CSS, JavaScript, AJAX, PHP và các Framework có sẵn vào xây dựng ứng dụng cổng thông tin cho ngành bảo đảm bảo mật, an toàn.
- Có thái độ đúng đắn về vận dụng tri thức về Lập trình Web để giải quyết các vấn đề trong học tập và công tác; có tinh thần nghiêm túc, trách nhiệm trong việc rèn luyện các kỹ năng thuyết trình và làm việc nhóm.
